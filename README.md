# AI_Reproductive_Health_SSA_Innovation_Challenge_Report
This repository contains code used to produce the AI for Reproductive Health In Sub-Saharan Africa Innovation Challenge Program Implementation Report

## Summary
**The AI for Reproductive Health In Sub-Saharan Africa Innovation Challenge** aims to build capacity by bringing together 
local experts in data science, engineering, and IT to develop solutions for local SRH priorities using large datasets. 
This innovation challenge seeks to harness the power of AI and machine learning (ML) to address systemic healthcare 
challenges such as poor patient engagement, inefficient inventory systems, and inadequate access to health information. 

It will bring together interdisciplinary teams to co-design, prototype, and test AI-enabled solutions tailored for 
real-world deployment across two thematic tracks

1. Access To Comprehensive Early Pregnancy Loss Care
2. Empowering Informed User Decision-Making for Contraception


## Setup

We are assuming you have `R Software` and `Rstudio IDE` installed. If not you can download and install 
[**R software**](https://www.r-project.org/) then followed by [**RStudio/Posit IDE**](https://posit.co/download/rstudio-desktop/).

## Run

After cloning the repository or downloading the ZIP, you also need the data files (**Data used for analysis** in the _data_ sub-folder of _AI_Reproductive_Health_SSA_Innovation_Challenge_Report_ folder.

Open `Rstudio` then set your working directory to the _AI_Reproductive_Health_SSA_Innovation_Challenge_Report_ folder.
